# SkillProof Requirement Register

This register tracks every functional and non-functional requirement specified in the SkillProof Master Prompt (derived from the college project report, Sections 4 & 5).

## Status Vocabulary
Per Operating Rule 5, requirements are strictly marked using only the following vocabulary:
- **NOT_STARTED**: No implementation work has begun.
- **IN_PROGRESS**: Active implementation or testing underway.
- **IMPLEMENTED**: Code and configuration exist, but automated tests have not yet executed and passed.
- **TESTED**: Automated tests executed and passed. The test command, execution timestamp, and results are recorded in `docs/test-report.md`.
- **BLOCKED**: Implementation cannot proceed safely or is missing external dependencies (reason and remediation steps documented).
